# Changelog

## 1.0.0
- Stable release approved after iterative project testing.
- Standardized desktop normal dropdowns and mega menus on Bootstrap native click behavior.
- Reliable outside-click and Escape closing for desktop navigation.
- Finalized automatic mega-menu columns, grouped child links, featured media positions, container alignment and spacing.
- Finalized right-side mobile offcanvas navigation with nested `+ / −` controls.
- Mobile navigation accounts for the WordPress admin toolbar during development.
- Added local Bootstrap assets, standard WordPress templates, accessibility basics, editor styles, widgets and Customizer starter options.
- Added WooCommerce support with optional Account and Cart header actions.
- Cleaned WooCommerce catalog presentation and generic widget styling.
- Added developer customization boundaries and core-file warnings to documentation/CSS/JS.
- GPL-2.0-or-later release with bundled Bootstrap MIT license retained.
