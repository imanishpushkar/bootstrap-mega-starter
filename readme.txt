A lightweight Bootstrap 5 classic WordPress starter theme centered on native WordPress mega menus.

== Features ==
* Appearance > Menus mega-menu checkbox
* Automatic responsive mega-menu columns
* Optional featured image: left/right/top/bottom
* Bootstrap click behavior for desktop dropdowns and mega menus
* Right-side mobile offcanvas with + / - nested navigation
* WordPress admin-toolbar-aware mobile navigation
* Local Bootstrap assets
* WooCommerce support and optional Account/Cart header actions
* Standard templates, widgets, editor styles and accessibility basics
* Translation-ready and GPL-2.0-or-later

== Installation ==
Upload the theme ZIP under Appearance > Themes > Add New, activate it, assign a Primary Menu, and enable Mega Menu on a top-level item in Appearance > Menus.

== Developer note ==
For project styling, use the PROJECT CUSTOM CSS section in style.css or a child theme. Do not edit Bootstrap vendor files. Avoid modifying inc/class-bs5-mega-navwalker.php, inc/menu-fields.php, assets/js/mega-menu.js, or the marked BMS CORE navigation sections of assets/css/theme.css unless maintaining the menu engine itself. See README.md for details.
